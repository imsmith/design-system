A

Theme = chrome only; spectrum is invariant (recommended)

Theme controls bg / text / borders / the one accent. Data spectrum + status colors stay identical across all themes — so "green = neutral" never lies, whatever skin you're in.

B

Theme re-tints everything

Matrix makes the whole spectrum green-shaded, etc. Stronger aesthetic unity, but data semantics shift per theme and cross-theme comparison breaks.
